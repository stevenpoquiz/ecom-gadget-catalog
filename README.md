# GADGETOPIA – Minimalist Gadget Catalog Website

A modern, minimalist gadget catalog website designed to showcase and organize different technology products through a clean and user-friendly interface.

## Overview

**GADGETOPIA** is a gadget discovery platform where users can explore various technology products across different categories, including smartphones, computers, audio devices, gaming, smart home devices, and accessories.

The website focuses on simplicity, organized product presentation, and a consistent visual identity. It features a modern design combining dark navy blue, orange, and white to create a clean and technology-inspired browsing experience.

This project is developed using **HTML and CSS**, focusing on frontend structure, styling, layout organization, and visual design.

## Pages

The website consists of three main pages:

- **Home** – Introduces GADGETOPIA through a hero section, gadget categories, and trending products.
- **Catalog** – Displays a collection of gadgets in an organized product grid with category navigation, search, sorting, and filtering interface elements.
- **About** – Introduces GADGETOPIA, including its background, mission, vision, and key features.

## Technologies Used

- **HTML** – Provides the structure and content of the website.
- **CSS** – Handles the visual presentation, layouts, styling, and responsive design.

## Getting Started

To view the website locally:

1. Clone the repository:

   ```bash
   git clone <repository-url>
   ```

2. Navigate to the project directory:

   ```bash
   cd ecom-gadget_catalog
   ```

3. Open `src/pages/home.html` in your preferred web browser.

No additional dependencies or installation steps are required.

## Project Scope

This project focuses on frontend website design and development using HTML and CSS. It serves as a static website prototype demonstrating page structure, visual design, and user interface organization.
